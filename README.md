## 📌 Proyecto

Pipeline desarrollado para el procesamiento de series temporales ecológicas (Eddy Covariance / CTD), con enfoque en:

- Gap filling robusto para series con huecos estructurales
- Preparación de datos para analisis de complejidad
- Análisis de dinámica del sistema: Análisis en el espacio de las freciencias, Estabilidad, Complejidad
