# Tolerance Landscapes ecological workhorse: implementation contract

## Purpose

Use observed estuarine time series to instantiate the formal objects in the static Tolerance Landscapes paper without introducing a dynamics on generator space.

Primary ecological candidate: Elkhorn Slough NERR, South Marsh, with Azevedo Pond, North Marsh and Vierra Mouth as within-estuary contrasts.

## Frozen primary specification before empirical interpretation

The initial primary run is fixed as follows:

- state: `X_t = dissolved oxygen`;
- condition: `Z_t = (water temperature, salinity, depth)`;
- observational window: 60 days;
- window step: 7 days;
- transition lag: 1 hour (4 x 15-minute observations);
- oxygen-admissibility threshold: 3 mg/L;
- viability horizon: 24 one-hour steps;
- state discretization: six quantile bins plus the 3 mg/L threshold whenever it is not already a boundary;
- each condition variable: two globally fixed quantile bins;
- minimum transition count per conditioned state row: 20;
- minimum fixed-`nu_ref` regime support per state row: 0.90;
- primary input: observed QA/QC-passing rows only, with no gap filling.

These choices are not claims of ecological universality. They define the first falsifiable implementation. Thresholds, horizons, windows, lags and discretizations are varied in sensitivity analysis.

## Core empirical map

For each observational window `w`:

1. estimate `K_z^(w)(i,j) = P(X_{t+Delta}=j | X_t=i, Z_t=z)`;
2. compare `K^(w)` with a fixed reference generator using a perturbation-conditioned total-variation distance;
3. integrate candidate and reference generators over the same fixed reference perturbation law `nu_ref` and the same common support;
4. evaluate one-step expected dissolved oxygen, finite-horizon viable mass and conditional terminal-state diversity under a fixed reference initial-state distribution;
5. retain explicit support-coverage diagnostics for every comparison.

Successive window estimates are **not** interpreted as a trajectory generated by a law on generator space. They are observational estimates placed in a common generator geometry.

## Primary outputs

- `conditioned_tv_to_reference`: response-architecture displacement;
- `marginal_tv_to_reference`: displacement after perturbation marginalization;
- `aliasing_gap = conditioned_tv - marginal_tv`, computed with the same fixed state and perturbation weights so that marginal TV cannot exceed conditioned TV except for numerical noise;
- `joint_support_coverage`;
- `fixed_nu_weighted_coverage` and `fully_evaluable_state_weight`;
- `expected_do_1step_mg_l`;
- `viable_mass`;
- `terminal_entropy` and `effective_terminal_states`;
- raw-state summaries for direct comparison with the formal objects.

## Fixed-evaluation principle

Comparisons across windows hold fixed:

- bin definitions;
- the reference perturbation law `nu_ref`;
- reference state weights;
- viability threshold;
- horizon;
- distance definition.

The oxygen threshold is an explicit state-bin boundary. This prevents a bin that straddles 3 mg/L from being silently classified as entirely admissible.

This design reduces the risk that a changing environmental mixture or state distribution is mistaken for a change in response architecture.

## QA/QC and ManglarIA integration

The primary analysis uses observed data after QA/QC. Missing QA metadata is not silently treated as acceptable. Standard water-quality variables use accepted flags 0 and 5; corrected/calculated depth may additionally use flag 3. The annual audit records source-column choice, finite coverage, flag frequencies and gap structure.

Existing ManglarIA gap filling is reserved for a separate sensitivity run. Imputed observations must never enter the primary generator estimate without explicit labeling because an imputed value can manufacture a transition `X_t -> X_(t+Delta)`.

ManglarIA remains useful for gap diagnostics, univariate Fisher information, functional connectivity and regime summaries. The current multivariate FI implementation is not used as paper evidence until a defensible adjacency/geometry on multivariate states is specified.

## Spectral control

`manglaria-spectra` is used as a secondary temporal-confounding control, especially for tidal, diel and seasonal structure. Welch/LSFT, IRASA, cross spectra, coherence and phase can test whether an apparent generator difference is reducible to known periodic or spectral organization. These analyses belong primarily in the supplement.

## Alejandro Frank / MSI-TMSI bridge

Run A-Frank-Analysis on the same timestamped multivariate data and align its sliding-window output with TL windows.

Because `S = A A^T/M` and `T = A^T A/M` share the same non-zero eigenvalues, leading eigenvalue, leading variance fraction and eigenvalue-slope alpha are not treated as specifically temporal merely because they are reported by the TMSI pipeline.

The preselected main-text external organization descriptor is **normalized lagged irreversibility `phi_normalized`**, derived from the antisymmetric component of lagged covariance. `leading_temporal_extent` is the secondary candidate. MSI spectra, Marchenko-Pastur comparisons, spectral exponents and the remaining complexity diagnostics belong in the supplement unless the preregistered main descriptor proves technically unusable.

## Main empirical falsification tests

1. **Same state, different architecture**: identify temporally separated windows with similar mean DO but large *direct* generator-to-generator conditioned distance. A difference between two distances to the reference is not accepted as evidence for this test.
2. **Same expected response, different viable futures**: identify windows with similar one-step expected DO but different viable mass or future diversity.
3. **Perturbation aliasing**: identify comparisons with small marginalized distance and larger conditioned distance under the same fixed evaluation law.
4. **Complexity non-redundancy**: test whether TL displacement is redundant with, or complementary to, the preselected temporal organization descriptor `phi_normalized`.
5. **External event alignment**: only after the above quantities are fixed, compare them with independently recorded hypoxia, rain, bloom or weather events.

## Synthetic validation gates

Before interpreting ecological results, the code must pass known-answer tests including:

- identical generators imply zero distance;
- distinct conditioned generators can be identical after a 50/50 perturbation mixture;
- the paired aliasing gap obeys the total-variation convexity inequality;
- a known absorbing/admissible Markov chain yields the analytical finite-horizon viable mass;
- a sparse perturbation support fails the fixed-`nu_ref` coverage gate rather than being silently accepted;
- the 3 mg/L criterion is an exact bin boundary and leaves both admissible and non-admissible bins when the data span the threshold.

## Sensitivity analysis

At minimum vary:

- windows: 30, 60, 90 days;
- transition lag: 15 min, 30 min, 1 h, 3 h;
- oxygen thresholds: 2, 3, 4, 5 mg/L;
- viability horizons: 6, 12, 24, 48 h;
- state and perturbation discretization;
- minimum support gate;
- conditioned TV versus payoff-induced distance;
- observed-only versus explicitly labeled gap-filled input.

No result should enter the paper solely because one specification looks visually compelling.
